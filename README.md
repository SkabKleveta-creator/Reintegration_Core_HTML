# Reintegration Core — District 01 v1.18.0

## Lowered Ceiling / 64x20 Scrolling Corridor Patch

This pack explores Ken's correction: keep the 64-column scrolling room width, but reduce room height by lowering the ceiling instead of cutting useful floor logic.

## Main file

- `reintegration_core_district_01_lowered_ceiling_v1_18_0.html`

## What changed

- Room logic is now **64 wide x 20 tall**.
- The playable structure is now a tighter horizontal corridor.
- Top dead-air/ceiling space has been removed.
- Floors were rebuilt into a clearer three-tier corridor pattern.
- Primary entrance / primary exit remains the default.
- Grappling Hook remains fixed-anchor only.
- Grapple anchors remain off ladder columns.
- No jump was added.

## What this is testing

Whether the game feels better when the map is less vertically tall and more horizontally intentional.

Acceptance question:

> Does 64x20 create a cleaner scrolling-system corridor, or does it feel too compressed?
